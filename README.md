# Maze Escape — The Lost Labyrinth

A browser-playable Java mini project. Java 21 + Spring Boot provides the maze/game API; HTML, CSS and Canvas render the game.

## Features
- Randomized maze generated by randomized depth-first search
- Keyboard (arrows/WASD) and mobile touch controls
- Easy, Medium and Hard levels
- Collect a key to unlock the exit
- Traps, three lives, score, move counter, win/lose and replay
- No database or paid APIs

## Run locally
Requirements: JDK 21 and Maven (or use an IDE with Maven support).

```bash
mvn spring-boot:run
```
Open http://localhost:8080

Build a deployable jar:
```bash
mvn clean package
java -jar target/maze-escape-1.0.0.jar
```

## Deploy on Render
1. Push this folder to a GitHub repository.
2. On Render, create **New + → Web Service** and connect the repository.
3. Runtime: Java (if offered) or Docker. For the Java build environment use:
   - Build command: `mvn clean package`
   - Start command: `java -Dserver.port=$PORT -jar target/maze-escape-1.0.0.jar`
4. If Render's environment doesn't provide JDK/Maven, use the Dockerfile included in this repo.
5. Deploy, open the assigned `https://...onrender.com` URL, and test creating a game, movement, traps, key and exit.

Free hosting may sleep when idle and the first request can take a little time. In-memory game sessions reset when the service restarts; this is acceptable for this demo.

## API
- `POST /api/new` body `{"difficulty":"medium"}`
- `GET /api/state/{id}`
- `POST /api/move/{id}` body `{"direction":"up"}`

## Notes
This is a student project/demo, not a security product. Game state is in server memory and has no account system.
